About the project

Unreal Engine

This is a little project I'm putting together to show off the little bits I've learned in Unreal and keep those skills sharp. The end goal is to make it a multiplayer experience and share it with some friends!

It's currently populated by simple AI enemies for something to test against. I built them to track and kill the player once they've been spotted. By default they stay at the location I place them; but once they see a player inside the BTService "Update Player Location If Seen" They instead begin chasing them. If they catch up they then open fire for as long as the player is within range. If they lose sight of the player; they begin to investigate; searching wherever they were last seen before returning to their start point.

In terms of the code; I wanted to keep things scalable; as the project has a lot of room to change and grow as I continue working on it. An example of this is keeping the gun and character separate; and letting the gun code handle all of the shooting logic. This way if I decide down the line to add alternative guns to play with; their integration will be a lot simpler.

I also handled the health bar as a percentage of max health; so the UI could function the same regardless of how big or small the max health is. And once it hits 0 (Or tries to dip below 0 and gets capped there) I have an "IsAlive" variable ready to store that information so having code count/react to character death will be smooth and easy.
